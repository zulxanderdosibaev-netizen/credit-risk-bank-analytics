
# 📊 Credit Risk & Portfolio Analytics (Power BI & SQL)

## 📌 Project Overview

## 🔍 Root Cause Analysis & Business Insights
1. **Критика в Credit Score:** В группе **Poor (<600)** уровень дефолта составляет **49.14%** (каждый второй кредит не возвращается).
2. **Перекредитованность:** Средний DTI **52.34%** показывает, что заемщики отдают больше половины дохода на погашение долгов.
3. **Дисбаланс доходности:** Ставка **12.69%** при дефолтности **24.29%** генерирует чистый убыток для банка.

---

## 💼 Business Recommendations
* **Стоп-фактор:** Ввести запрет на автоматическое одобрение заявок для категории **Poor (<600)**.
* **Лимиты DTI:** Ограничить выдачу кредитов клиентам с DTI > 45%.
* **Риск-ориентированное ценообразование:** Повысить процентные ставки для групп повышенного риска до 20%+ для компенсации убытков.

## 🛠 Tech Stack & Architecture
* **SQL Server (T-SQL):** Проектирование схемы (`dim_borrowers`, `fact_loans`), первичная очистка и трансформация данных (`TRY_CAST`, `ISNULL`).
* **Power BI / DAX:** Моделирование «Звезда», разработка мер и интерактивных визуэлов.

```dax
Total Volume = SUM(fact_loans[loan_amount])
Total Loans = COUNT(fact_loans[loan_id])
Total Defaults = SUM(fact_loans[is_default])
Default Rate % = DIVIDE([Total Defaults], [Total Loans], 0)
